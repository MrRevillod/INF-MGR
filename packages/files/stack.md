Tablas: \begin{tabular} o \begin{tabularx} → Arrays de filas/celdas limpias.
Imágenes: \includegraphics[opciones]{ruta} → Objetos con path y caption opcional.
Listas: \begin{itemize} o \begin{enumerate} → Arrays de items (\item extraídos).
Ecuaciones: $...$, $$...$$, \begin{equation}...\end{equation} → Contenido limpio.
